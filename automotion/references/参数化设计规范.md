# 镜头参数化设计规范（v7）

> 生成日期：2026-08-05
> 依据：20 个试点镜头（10 类 × 2）的实际参数化经验
> 适用范围：方法论（M1 已应用；后续镜头改造与新镜头沿用）

## 1. 核心原则

- **画面实体必须参数化，禁止内容硬编码**：画面中出现的每一个视觉实体（刻度 / 格子 / 柱子 / 卡片 / 词块…）及其属性（数量 / 位置 / 内容 / 数值）都必须可配置；渲染逻辑遍历 props 数据，模块级常量只保留为默认值示例，禁止内容硬编码在组件里
- **内容参数化，表现不动**：内容（文字 / 列表 / 数据 / 素材路径 / 标题）进 props；表现（动画时序 / 节拍 / 位移 / 布局结构）保持
- **颜色一律走 G 色板**：禁止硬编码 hex，统一引用 `lenses/_system/colors.ts`（G.bg / G.ink / G.mid / G.bar / G.line / G.card / G.border / G.panel / G.accent）
- **默认值 = 中性示例或留空**：不写死项目内容（品牌 / 政策 / 专有产品 / 销售数据形态文案）；**镜头名 / 手法名标签一律不出现在画面上——全部去掉，不留默认值**（不是中性化替换）；品牌默认值已清（阶段 1：Notion AI / perplexity / ClickUp Space / Find in Slack 等）
- **所有 props 可选 + 有默认值**：严禁必需 props 无默认（会导致运行时 NaN / undefined 崩溃）

## 2. 可变项识别

**参数化（进 props）**：

- 文字：标题 / 词 / 句子 / 按钮 / 字标
- 列表：行列表 / 卡片组 / 轮换词 / 柱数据
- 数据：数值 / 百分比 / 单位 / 基准值
- 素材路径：截图 / 图片
- 内容承载：卡片 / 新景 / 背后内容
- 画面实体：刻度 / 格子 / 卡片 / 柱 / 词块等，及其数量 / 位置 / 内容 / 数值属性，全部入 props
- **占位条 / 装饰条（圆角方块、粗线条、卡片占位线条）：本质是图标或文字，必须参数化为 `icon` / `rows` 等数据，禁止以假线条充当内容**

**不参数化（保持）**：

- 动画时序：帧段 / 节拍 / 缓动
- 布局结构：尺寸 / 间距 / 坐标
- 表现细节：胶带样式 / 光效参数 / 投影——纯表现保持；**具象占位条（方块 / 线条）不在此列，必须参数化**
- 图标 SVG：难从 JSON 传，用内置图标集选择（如 IntegrationHubMap 的 icons）

## 3. props 设计规范

- 接口命名：`XxxProps`，与组件同文件导出
- 组件签名：`React.FC<XxxProps> = ({ a = default, b = default }) => {...}`
- 字段命名语义化：`text / title / subtitle / label / value / rows / wordmark / buttonText / ...`
- 列表用对象数组：`{ label: string; value: string }[]`、`{ word: string; dur: number }[]`
- 数量可变：布局按数量自适应（见 §5）
- props 名避免与组件内动画变量重名（如 `summary` 与动画进度变量）

## 4. 内容形态机制

内容承载（卡片 / 新景 / 背后内容）不写死单一结构：

```ts
// 示例：InkBleedReveal newScene / MaskingTapeSlap card
{ type?: 'rows' | 'image'; title?: string; rows?: { label: string; value: string }[]; image?: string }
```

- `type` 字段 + 内置渲染器（当前：`rows` 行列表 / `image` 图片）
- 加新形态 = type 联合加值 + 渲染器加分支，**不改 props 结构**
- 约束：storyboard 是 JSON，不能传 ReactNode / children——形态必须数据可表达
- **占位条承载规则**：卡片 / 面板内的假线条（G.bar / G.line）是「未参数化内容」的信号，必须换成 `rows` 文字行或 `icon` 图标；默认数据给中性示例（如「指标一 +18%」），不给空

## 5. 自适应

内容变化后几何要跟着算，禁写死：

- 字号：`fontSize = min(上限, max(下限, 可用宽 / (字符数 × 0.58)))`（英文近似，中文更宽）
- 卡宽随数量：`cardW = min(固定上限, (总宽 - 边距 - (n-1) × 间距) / n)`
- 与内容相关的长度动态计算：下划线长度、合拢终点、标签宽度
- 长内容加 `overflowWrap: break-word` 防溢出

## 6. 演示痕迹清理清单

参数化时一并清掉（除非是内容本身）：

- 镜头名 / 手法名标签（画面文字 = 镜头名，如 "CEL FLASH STOMP" / "MASKING TAPE SLAP" / "LINE UNFOLD PANEL"）→ **全部去掉，不留默认值**
- **标题分类规则**：改造前先区分两类标题——① 手法名标签（非内容）→ 去掉；② 标题承载 / 内容标签（镜头功能就是显示标题，如标题卡、顶部小标签、数据标签）→ **中性化保留 + 参数化**。执行前必须把每批镜头的「去掉 or 中性化」清单给用户确认，不自行判断
- 占位条（圆角方块 / 粗线条 / 卡片占位线条）→ 参数化为 `icon` / `rows` 文字数据
- 调试角标（boil on/off、on 3s/on 1s、FREEZE）
- 演示占位（FakeDashboard / Card 骨架 / TitleBlock）→ 换中性内容承载
- 素材引用缺失 → 素材入库或参数化路径

## 7. 时间处理

- 每个镜头必须声明时长策略（弹刚 ShotTime / 口播锚点 cueSec|revealAtSec / 固定帧），新镜头默认接入弹刚；细则见 **references/镜头时间策略声明规范.md**
- 时序帧段保持（刚性 / 弹性在 ShotTime 分段声明；文件头「=== 时间特性 ===」注明）
- 内容相关的时序按数量动态生成（cue 数组 = `rows.map((_, i) => 起点 + i × 间隔)`）
- 已用 engine（`useShotFrame` / `ShotTime`）的镜头保留，参数化时按内容数量动态生成 ShotTime
- 内容与口播逐项/单事件对应的镜头加 `cueSec`/`revealAtSec` 锚点（用 `scripts/query-cues.py` 查词级时间）；连续滚动/流程动画/无逐项锚点/内容结构与镜头错位的不做对齐

## 8. 验证流程（每个镜头必做）

1. esbuild 编译通过：
   `npx esbuild <file> --bundle --external:remotion --external:react --external:react-dom --external:@remotion/motion-blur --loader:.json=json`
2. 默认渲染成功：`npx remotion still <entry> <compId> out.png --frame=<中段帧>`
3. 自定义 props 渲染成功：`--props=<json 文件>`，覆盖主要参数
4. **编译 ≠ 渲染**：运行时 NaN / 素材 404 只有渲染能暴露，两步都做

## 9. 教训清单（试点踩过的坑）

- props 名与组件内动画变量重名（`summary`）→ 命名区分
- 必需 props 无默认 → 默认值兜底（PaperTitleCard duration/words）
- Card 组件无 children 插槽 → 用容器 div + 内容组件
- CRLF 文件导致 apply_patch 匹配失败 → 先统一 LF
- 默认空字符串导致新增视觉元素看不到 → 新元素默认给非空示例
- 暗色背景 → 用户要求纸色（G.bg），删暗色背景图 / 遮罩
- **占位条 ≠ 装饰**：圆角方块 / 粗线条 / 占位线条是「未参数化内容」，本质是图标或文字——参数化时换成 `icon` / `rows` 数据，不是留着当装饰

## 10. 产出物

每个镜头参数化完成的标准：

- 组件：props 接口 + 默认值 + 自适应 + 色板统一 + 演示痕迹清理
- 文件头注释更新（=== 可调参数 === 列出 props）
- 渲染验证通过（默认 + 自定义）
- 提交：一次一镜头（或一次一相关类型组）
