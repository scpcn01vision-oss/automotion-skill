# 镜头时间策略声明规范（v7）

> 生成：2026-08-14（镜头库全量补齐）
> 目的：让全部 122 个镜头具备明确的时间策略，保证镜头内部节奏能适配段落真实时长（口播语速）与口播锚点
> 依据：`engine/time.ts`（刚弹映射）、`engine/useShotFrame.ts`、已接入样板（TextAsMask / BeatStepListThemeCycle / CardFlipReveal / MarkerUnderlineTitle / SmearMultiples 等）

## 1. 三种时长策略（每镜头必选其一，在文件头声明）

### 1.1 弹刚 ShotTime（推荐默认）

- 镜头声明 `SHOT_TIME: ShotTime`，用 `useShotFrame(SHOT_TIME)` 替代裸 `useCurrentFrame()`
- 时间轴由「刚性段（固定帧数，不可压缩）」+「弹性段（按段落实际时长分配剩余帧）」组成，映射回原始坐标后组件内 interpolate 关键帧**无需改动**
- 段长不足 `minFrames` 时引擎回退原始帧（动画按原速、可能被截断——与未接入时行为一致，不更差）

样板（分段 + minFrames 写法见 `lenses/light/text-as-mask/TextAsMask.tsx`、`lenses/minimal/beat-step-list-theme-cycle/BeatStepListThemeCycle.tsx`；动态按内容数量生成见 `lenses/light/card-flip-reveal/CardFlipReveal.tsx`）。

### 1.2 口播锚点（cueSec[] / revealAtSec）

- 内容与口播逐项/单事件对应时使用，props 增加：
  - `cueSec?: number[]`：逐项锚点，段内秒，与内容数组一一对应（如每张卡/每个词）
  - `revealAtSec?: number`：单事件锚点，段内秒（如"某句口播开始时放大/横移"）
- 锚点提供后该镜头用真实帧 `useCurrentFrame()` 触发关键事件；未提供时走弹刚/固定时序
- 锚点时间用 `scripts/query-cues.py` 从转录词级时间查询

样板：`MarkerUnderlineTitle`（revealAtSec）、`CardFlipReveal`（cueSec）、`BeatStepListThemeCycle`（cueSec）、`SmearMultiples`（revealAtSec，固定帧策略下的锚点）。

### 1.3 固定帧

- 镜头节奏本身与口播/段长无关（UI 流程、装饰、粒子、连续滚动展示等），声明"固定帧 + 尾部静止/循环"，不随段长伸缩
- 必须写明理由（为什么不适合伸缩/锚点）；纯属"没接入"不算固定帧策略

## 2. 每镜头必填声明（文件头注释）

在组件文件头部「=== 时间特性 ===」注明：

```
// === 时间特性 ===
// 策略: 弹刚 ShotTime（或 口播锚点 / 固定帧）
// 刚性（不可压缩）: <分段区间与理由，无则写"无">
// 弹性（可伸缩）: <分段区间；锚点模式下写"锚点外其余时段">
// 适配注意: <minFrames 依据、短段行为、动态生成规则>
```

## 3. 接入步骤（执行者照做）

1. 读组件源码，标出全部关键帧（interpolate 输入区间、归一化比例、循环逻辑）
2. 画像：划分刚性段（动画核心帧，不可压缩）与弹性段（铺垫/过渡/收尾/hold），确定 `minFrames`
3. 注入 `SHOT_TIME` 常量 + `useShotFrame` 替换（`to` 必须等于该镜头 Composition 的 `durationInFrames`）
4. 需要口播对齐的镜头：加 `cueSec`/`revealAtSec` props，用 query-cues.py 查时间
5. 验证：`npx tsc --noEmit` 0 错误 + 默认渲染 + 自定义 props 渲染（`npx remotion still lenses/Root.preview.tsx <镜头id> out/x.png --frame=<帧>`）；锚点镜头抽查锚点前后帧差

## 4. 兜底与精修的分工

- **保守兜底**（批量）：未接入镜头先统一加「整段弹性」ShotTime（单段 [0, durationInFrames]，minFrames 按关键帧估算），保证能随段长伸缩；`useCurrentFrame` 多处调用/特殊逻辑的镜头人工处理
- **逐个精修**（按组分批）：按 §1.1 画像刚弹分段、细化 minFrames；每批验证后进入下一批
- **口播对齐按需**：内容与口播对应的镜头加锚点；判断标准见 skill `references/自动填参-映射规律-M4.md` 3.5 节（口播无逐项锚点 / 连续滚动展示 / 流程动画 / 内容顺序与镜头结构错位 → 不做对齐）

## 5. 验收标准

- 全部 122 个镜头文件头含「时间特性」声明
- `npx tsc --noEmit` 0 错误
- 每批渲染抽查：帧差验证锚点事件时刻或动画铺满段长
